# Project Guidelines & Standing Rules

## 1. Full Mobile Optimization
The entire website must be completely optimized for all standard mobile devices (320px – 768px):
- Each and every section must render cleanly without overflow, clipping, or visual distortion.
- Touch interactions, font sizes, paddings, and media must scale proportionally.

## 2. Mandatory Mobile Support for All Future Modifications
Any new section added, feature created, or code updated must automatically and by default be optimized for mobile screens.

## 3. Desktop Preservation
Never alter or degrade any current desktop feature, layout, or section styling. Mobile customizations must always be applied via targeted responsive media queries.
